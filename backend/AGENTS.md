# Backend

Владелец этой папки отвечает за HTTP API, валидацию, сохранение и представление запусков прогноза. Предметные расчёты находятся в `forecasting/`. Импортируйте его публичный интерфейс после согласования контракта.

Формат ошибок: `{"error": "понятное сообщение"}`. Не возвращайте синтетический прогноз при отсутствии модели или погодных данных. При изменении JSON контракта согласуйте и обновите `shared/API.md`. Все запросы проверяйте до вызова прогнозного ядра.
