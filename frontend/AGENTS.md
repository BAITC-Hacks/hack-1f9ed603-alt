# Frontend

Владелец этой папки отвечает за сценарий пользователя, отображение почасового прогноза и ошибок. Все вызовы API находятся в `src/api.ts`. Контракт — `../shared/API.md`; перед его изменением согласуйте новые поля с backend и forecasting.

Показывайте отдельно загрузку, пустые данные и ошибку. Не подменяйте ошибку API демонстрационным прогнозом. Нормализованную мощность подписывайте как долю от 0 до 1, пока не известна номинальная мощность турбин.
